# Emerald Globe Pro · 月流量与剩余价值设计方案

日期：2026-10-11。目标主题：当前工作区的 Monitor BoxPro / Emerald Globe Pro。

采用 **翡翠玻璃卡片 + 地球状态浮标 + 节点三格信息带**。保留原主题的翡翠渐变、透视网格和交互地球，把参考图里的信息组织方式融入现有页面。

这套方案已在 v0.2.4 接入正式主题，正式组件位于 `src/`。临时设计预览及本地测试产物已清理。

## 节点三格信息带

- 三格等宽，桌面常规节点卡下保持一排；加「实时速率」「当月流量」「到期与价值」小标题，直接区分数据含义。
- 上下行方向用图标和上下顺序表达：上行在上，下行在下。实时速率保留绿 / 蓝，月流量用正文与次级文字颜色，减少资源指标下方的颜色干扰。
- 标题下显示「在线 30 天」和「¥29.90 / 月」。右格金额显示「¥11.96」代表剩余价值，付款标价与剩余金额各有位置。
- KB/s 窄格取整；月流量保持一位小数；金额通常两位小数。较长金额可显示「₩7.5万」，完整金额保留在提示中；大天数可显示「剩900天」。
- 三网色条沿用现有延迟组件，信息带下方用细分隔线连接；此次主要调整间距和圆角。

## 剩余价值口径

沿用当前主题的 `calculateNodeFinance` / `summarizeFinance`，并参考 Emerald Globe Pro 的汇总卡片表现：

```text
单节点剩余价值 = 本付款周期价格 × max(剩余天数, 0) ÷ 本付款周期参考天数
汇总剩余价值   = 各可计算节点剩余价值换算为目标币种后相加
```

月付按 30 天，季付按 90 天，半年付按 180 天，年付按 365 天；自定义 N 个月按 N × 30 天。例如月付 ¥29.90、剩余 12 天，显示 ¥11.96。

- 节点卡保留原币种；总览默认 CNY，并沿用现有汇率与币种设置。
- 包含离线但仍有有效付款和到期信息的节点，在线状态不决定剩余价值。
- 今天到期或已过期的有效周期费用归零；多周期预付按剩余天数折算，金额可大于一次周期价格。
- 免费为 0。一次性购买没有折算周期时显示 `—`；缺价格、周期、到期或汇率时提示原因。全部不可计算显示 `—`，部分可计算显示「部分计入 · N 台未计入」。
- 隐藏费用时总览显示「费用已隐藏」，节点金额隐藏，保留非金额的到期信息。实际接入继续使用现有未登录隐藏费用逻辑。
- 剩余价值是按时间折算的估算金额，不等同于退款余额。汇率状态沿用现有提示。

月上下行直接读取主控的 `month_tx` / `month_rx`，不从累计流量推算，也不把 `month_used` 拆成上下行。资源区的「本期流量」继续按主控计费方向计算，可能与月上下行的总和不同。

如果主控将 `month_*` 定义为自定义重置周期，正式接入应随重置日使用「当期流量」文案；自然月口径需要主控提供对应自然月数据。当前官方示例重置日为每月 1 日。

## 在线状态浮标

参考截图三、四的 `● 27  ● 3`，将数量放到地球容器左上角。采用单一底板与两组数值，整体约 90 × 32 px；移动端触控区域至少 40 px 高。

- 总体在线用翡翠色，离线用琥珀色；节点自身离线警告仍采用现有红色。
- 颜色之外提供完整的可访问名称；点击可查看中文状态说明，键盘 Enter / Space 也能展开，Escape 收起。
- 仅汇总或隐藏地球时，浮标移到节点工具栏；地图及 WebGL 回退使用同一个状态组件。
- 统计默认跟随当前节点分组。搜索只筛选列表，浮标数量仍表示当前分组总量。
- 0 个节点显示在线 0，离线项隐藏；刚连接但未上报按主控 `online` 计数，节点卡继续显示「等待上报」。

## 视觉与响应式规范

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#F8FAF9` | `#101A24` |
| 翡翠主色 / 在线 / 上传 | `#059669` | `#46C499` |
| 下载 | `#2563EB` | `#84AED3` |
| 离线统计 | `#A36A07` | `#EFB747` |
| 正文 | `#18181B` | `#E2ECE7` |
| 次级文字 | `#71717A` | `#90A39E` |

正文使用现有系统字体及 PingFang SC / Microsoft YaHei 回退；指标采用等宽数字排列。总览主数字 24–28 px，中等桌面宽度的长金额调整为 18–22 px；节点标题 14–16 px、节点主指标 11–13 px。圆角分别为总览 14 px、节点卡 16 px、信息带小格 10 px；浅色白玻璃，深色蓝绿玻璃，保留透视网格。

桌面保留左侧 2 × 3 总览、右侧地球，节点常规尺寸为四列；中等宽度转三列或两列。手机总览转 2 列 × 3 行、地球在下、节点为单列；三格信息带仍一排，使用简写或换行解决长金额，不整体缩小字体。320 px 起保持页面无横向滚动。

减少动态效果沿用现有配置。浮标数值变化不闪烁、不循环跳动，背景与金额不增加常驻动画。
