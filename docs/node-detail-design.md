# BoxPro 节点详情页优化方案

日期：2026-10-12。状态：**已按用户本轮指示在本地实施，尚未推送 GitHub 或发布主控**。

## 目标与现状

让首页每个节点卡片和列表项都能打开完整详情，查看当前运行情况、资源历史、线路延迟、硬件系统、流量和费用。保持 BoxPro 的翡翠色与浅色/深色外观。

当前并非只有点击事件故障：`NodeCard.vue`、`NodeList.vue` 没有详情链接，`App.vue` 没有详情视图。首页只读取实时快照和短时延迟，尚未接入资源历史。数据整理还丢弃了一些详情字段，实施时需要一并保留。

本轮已按此方案修改主题源码并执行本地验证；预览全部数值和曲线均为设计示例，不是实测数据。原工作区的 README.md、src/App.vue、theme.json 既有修改已保留；不会自动推送 GitHub 或更新正在运行的主控。

## 推荐交互

- 卡片标题及明确的「查看详情 →」使用真实链接；点击卡片空白位置也进入详情。鼠标悬停轻微强调边框；入口在手机上始终可见。
- 卡片现有的更多信息、延迟控件、链接及选中文字不会误触跳转。键盘用户通过链接进入，不把整个含按钮的卡片嵌套进一个大链接。
- 列表的节点名称同样可点；卡片和列表进入同一详情。
- 使用 `/#/node/{id}` 的轻量 hash 导航。直接打开、复制链接、刷新、浏览器前进后退都能保持正确节点；无需新增路由库或反代配置。
- 顶部提供返回、节点选择和上一台/下一台。切换顺序沿用进入详情时的筛选和排序结果，明确显示「当前分组 · N 台」；搜索或筛选没有包含直达节点时，用全部可见节点作为切换范围。
- 返回首页恢复分组、搜索、排序、卡片/列表及滚动位置，焦点回到入口。

采用完整页面，桌面可利用图表宽度，手机按同一结构顺序阅读。

从参考图保留「完整主机信息 + 四张资源趋势 + 全宽多线路延迟」的功能，减少首屏十六张同等权重指标卡的重复。需要频繁判断的 CPU、内存、磁盘和实时网络突出显示，负载、Swap、进程和连接数用一条信息带补全。费用有明确区域，避免和资源趋势争夺首屏空间。

## 数据与展示口径

| 内容 | 数据 | 展示规则 |
| --- | --- | --- |
| 在线、离线、等待上报 | online、metrics、metrics_invalid、last_seen_ago | 在线与有没有指标分开；未知用 `—`，不补零 |
| CPU、负载 | metrics.cpu、load | CPU 百分比，负载明确 1/5/15 分钟；负载不显示为百分比 |
| 内存、Swap、磁盘 | used / total | 用量、容量、百分比；缺可选字段不影响其它指标 |
| 上下行 | net_tx、net_rx | 分别显示上传/下载，带 B/s、KB/s、MB/s |
| 进程与连接 | procs、tcp、udp | TCP 连接与 UDP 套接字分开，不将 tcp+udp 命名为总连接 |
| 运行时长 | metrics.uptime | 指系统运行时间，不冒充持续在线时长或可靠性统计 |
| 硬件与系统 | cpu_name、cpu_cores、os、kernel、arch、virt、agent_version | 只展示接口提供的事实，不添加 CPU 性能等级、排名或厂商猜测 |
| 价格与月均 | price、currency、billing_cycle | 共用已有费用函数；月均是录入周期标价折算 |
| 到期与剩余价值 | expires_at、expires_in | 剩余天数优先用 hub 值；价值是按时间折算估算，共用已有算法和币种 |
| 本期流量与配额 | month_rx、month_tx、month_used、traffic_limit、traffic_mode、traffic_reset_day | 上下行与计费量分开；自然月或当期按重置日命名；无配额用无限制 |
| 累计流量 | total_rx、total_tx | 以实时快照为准，不用历史图表积分替代 |
| 地址 | 登录状态且返回 ipv4/ipv6 等字段 | 匿名不画地址区块；不承诺截图中匿名无法获取的 IP |

内核、Swap、连接、进程、Agent 等字段加入类型和归一化时为可选字段；不得为了补充详情将旧主控原本有效的核心指标全部判为坏数据。

详情与首页共用当前生效的 `show_cpu`、`show_memory`、`show_disk`、`show_speed`、`show_traffic`、`show_total_traffic`、`show_uptime`、`show_node_metadata`、`show_remark`、`show_expiry`、`show_ping` 及费用显隐条件，保留已有个人显示偏好规则。费用继续遵守已有站点和登录限制，直达详情或个人偏好不能绕过。缺数据用 `—` 或对应空态；被隐藏的区块直接不显示。

## 图表交互

- CPU：平均值实线，可选峰值虚线；纵轴百分比固定 0–100%。
- 内存/磁盘：用量实线、总容量参考虚线。总容量是当前容量，历史硬件容量变化没有快照时不伪装成历史容量。
- 网络：下载蓝色、上传翡翠色；可切换峰值。平均速率与峰值明确标注，单位随量级变化。
- 桌面资源图 2×2，延迟图占满行；手机单列，每图保持可读刻度。悬停或手机点选显示时间、数值及单位，连续资源图共享时间指示位置。
- 延迟线路来自接口 `probes` / `task_id` 和主控排序，支持勾选；不限于截图中的三条线路。卡片首页的 `ping_max_lines` 仅控制首页，详情列出配置允许的全部线路，不强制只显示三条。
- 延迟与丢包分开：曲线画延迟，线路摘要显示选定窗口丢包率；延迟为 null 时断线，不画成 0ms。存在 band 时可展示波动范围。
- 默认历史断档不连线，不补 0。延迟图可选“平滑显示”：真实采样点使用不产生虚假峰值的平滑曲线；单次短缺测可用虚线标注过渡，明确超时（latency=null）和长断档仍然断线，不伪造测量或改变丢包率。浏览器记住开关设置。图例颜色、刻度和状态文字适配浅色/深色。
- 资源范围和延迟范围独立保存，默认最近 1 小时；实时数值由现有 WebSocket 更新，历史默认每 60 秒刷新，切回前台立即刷新。
- 预设档位按 `/api/me.history_days` 生成，常见为 1 小时、6 小时、1 天、7 天、30 天；删除超出保留期的档位，补上实际保留期。旧主控没有该字段时只提供保守短时档位，不伪称有 30 天。
- 首版不提供任意日期起止选择；官方接口只支持最近 N 小时。需要自定义时可在后续增加「最近 N 小时/天」。
- 图表请求共享每种系列一个响应；按图宽决定 points，限制 60–1440。优先轻量 SVG 组件，延迟加载详情；不为首页每张卡片加载完整历史图表。

## 稳定性与验收标准

- 卡片和列表均能进入同一节点；更多信息和文字选择不会误跳转；返回恢复筛选、滚动和焦点。
- 详情地址复制、刷新、浏览器前进/后退及直达离线节点正常；删除或不可见的节点显示「节点不存在或无权查看」和返回入口。
- 快速切换节点或范围不会被旧请求覆盖；离开详情、页面隐藏或权限变化取消请求并停止定时刷新；最多当前节点请求，不加载所有节点历史。
- 历史失败只影响图表，当前状态和资料可读；保留已有曲线时明确最后刷新时间并提供重试。401 撤回受限资料，404 不泄漏节点信息，429 退避重试。
- 离线展示可用的历史和基本资料，当前指标为 `—`；等待上报、损坏指标、没有历史、没有延迟任务都有对应文案。
- 部分可选字段缺失不会白屏；0 值显示为 0，null/缺失不冒充 0。
- 隐藏费用的未登录详情不显示费用、估值或发起估值汇率请求；匿名 IP 区块隐藏。
- 320px 手机及常见桌面无页面横向溢出；按钮触控、键盘、焦点和减少动画偏好可用。
- 不改变首页地球、已有费用算法、个人选择、显示偏好和计费流量口径。
